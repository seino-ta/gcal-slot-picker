# カレンダー日程ピッカー

Googleカレンダーの週/日表示で好きな時間帯をドラッグ選択すると、メールに貼れる日程候補テキストに変換してコピーできるChrome拡張です。

## インストール

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をON
3. 「パッケージ化されていない拡張機能を読み込む」→ このフォルダを選択

## 使い方

1. [Googleカレンダー](https://calendar.google.com)を**週表示または日表示**で開く
2. 右下の 📅 ボタンをクリックして選択モードON
3. カレンダー上を**ドラッグ**して候補の時間帯を追加（クリックで1コマ追加）
4. パネルの「コピー」でテキストをコピー → メールに貼り付け

```
・8/14(木) 10:00〜11:00
・8/15(金) 14:00〜15:30
```

### 操作

| 操作 | 動作 |
|---|---|
| ドラッグ | 候補の時間帯を追加 |
| 空き部分をクリック | 1コマ（選択単位分）追加 |
| 追加済みの枠をクリック | その枠を削除 |
| Esc / ✕ / 📅ボタン | 選択モード終了 |

- **単位**: 15分 / 30分 / 60分 のスナップ幅を選択
- **形式**: `8/14(木) 10:00〜11:00` / `8月14日(木) 10:00〜11:00` / `8/14 (木) 10:00-11:00`
- 同じ日の重なった・隣接した枠は自動でマージされます
- 設定（単位・形式）は自動保存されます

## 仕組み

- 週/日表示の日カラム `div[role="gridcell"][data-datekey]` の位置から日付・時刻を算出
  - `data-datekey` は `(年-1970)<<9 | 月<<5 | 日` でエンコードされている
- 選択モード中はグリッド上に透明オーバーレイを重ねてドラッグを捕捉（誤って予定が作られない）
- calendar.google.com は Trusted Types を強制しているため、DOM構築は `createElement` のみで行っている（`innerHTML` 不可）

## ファイル構成

- `manifest.json` — Manifest V3
- `content.js` — 本体（コンテンツスクリプト）
- `content.css` — UIスタイル
